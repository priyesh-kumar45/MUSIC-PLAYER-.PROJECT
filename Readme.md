# 🎵 Music Player Web Application

A responsive and interactive **Music Player Web Application** built using **HTML, CSS, and JavaScript**.

The project provides a modern music-player interface with song controls, playlist management, album artwork, progress tracking, repeat mode, shuffle mode, and responsive design.

## ✨ Features

### ▶️ Play / Pause Music

Play or pause the currently selected song using the central play button.

### ⏮️ Previous Song

Move to the previous song in the playlist.

### ⏭️ Next Song

Move to the next song in the playlist.

### 🔁 Repeat Mode

Repeat songs from the playlist.

### 🔂 Repeat One

Repeat the currently playing song.

### 🔀 Shuffle Mode

Play songs randomly from the playlist.

### 📃 Music Playlist

Open the music list and select any available song.

### 🖼️ Album Artwork

Each song has its own album artwork displayed in the player.

### 📊 Progress Bar

The progress bar displays the current position of the song.

Users can click on the progress bar to move to a different position in the song.

### ⏱️ Song Duration

The player displays:

- Current playing time
- Total song duration

### 📱 Responsive Design

The Music Player is designed to work on:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📲 Tablet
